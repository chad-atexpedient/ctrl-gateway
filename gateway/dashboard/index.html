Webhook Dispatcher

Fan-out events to HTTP endpoints. Each registered webhook subscribes to a list of event types (or * for all events). Delivery is async with retry + exponential backoff. Every attempt is logged into webhook_deliveries. HMAC SHA-256 signature when a secret is set.
