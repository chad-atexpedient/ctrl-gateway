An Expedient AI Project Apache 2.0 · self-hosted · single Python service

Routes every request to the cheapest model that can handle it — not just whatever’s hardcoded in your client.

CTRL Gateway sits between your application and your LLM providers — OpenAI, Anthropic, Google, Ollama, OpenRouter, Groq, Together, DeepSeek, and 15+ others — reachable through either an OpenAI-compatible or an Anthropic-compatible endpoint. It classifies every request by vertical and complexity, routes it to the cheapest sufficient model, falls back on failure, and learns from outcomes to improve future routing.

What it does

One gateway, the whole inference fleet.

An OpenAI- and Anthropic-compatible reverse proxy in front, a real routing brain behind it — not just a static model list with a load balancer.

⇄

Gateway

OpenAI- and Anthropic-compatible reverse proxy. Health checks, circuit breakers, streaming, concurrency control, per-tenant auth.

⌖

Router

Frozen sentence embedding + MLP classifier heads. 65 verticals, complexity scoring, code/math/reasoning flags, OOD detection — CPU-only.

⚖

Policy engine

Deterministic pre-routes → cost-first gate → uncertainty escalation → tier ladder. Budget-aware routing with Wilson confidence bounds.

☉

Model catalog

Auto-discovers models from OpenRouter, OpenAI, Anthropic, Ollama. Capability scoring, auto-tier assignment, spidergraph comparison.

↻

Data flywheel

Async reviewer labels every prompt; high-agreement samples become training data; auto-retrain with eval gate and auto-rollback.

✦

Extensions

Plugin system, A2A agent registry, IBM ContextForge connector, MCP discovery + unified facade, prompt templates, webhooks, tool cache.

🛡

Security

Prompt-injection detection, provider domain allowlist, host firewall, DNS-rebinding-resistant SSRF protection, audit log.

⚭

Multi-tenant

Per-user API keys tagged by wire format, rate limits, token/USD budgets, tier access, plan-based quotas. Tenant scoping on every extension table.

Request lifecycle

What happens between your request and a response.

Every call passes through the same pipeline — deterministic where it can be, learned where it should be.

Auth & injection check

Per-tenant API key resolution, then DB-backed regex profiles scan the prompt — block/alert/log actions, evaluated before any routing happens.

Classify

Embedding + MLP heads classify into 65 verticals plus complexity 1–5, with code/math/reasoning/long-output flags and out-of-distribution detection.

Route

Deterministic pre-routes (vision, medical, freshness) first, then cost-first tier selection or a budget-aware cascade chain, with escalation for low-confidence calls.

Transcode & dispatch

The payload is rewritten between wire formats (OpenAI, Anthropic, and every upstream's native shape) and sent with concurrency control, circuit breakers, and a retry/fallback ladder.

Review & learn

An async reviewer independently labels the exchange; high-agreement labels become curated training data that periodically retrains the router.

Security hub

Three layers, all configurable at runtime.

None of this requires a restart — profiles, allowlists, and firewall rules are all hot-reloadable via the admin API.

Prompt-injection detection

DB-backed regex profiles with severity and action (block/alert/log). Six built-in profiles cover jailbreak, role override, context escape, router manipulation, data exfiltration, and semantic DoS. Routing is never altered by injection signals — a blocked request returns HTTP 400 before routing runs.

Provider domain allowlist

Governs which LLM provider domains the gateway may talk to, with config- and DB-backed rules plus tenant-specific overrides. An optional host-level firewall enforces the same policy at the OS level on Windows or Linux.

SSRF protection

Validates outbound HTTP from every integration point — A2A, ContextForge, MCP discovery, webhook delivery. Blocks loopback, private, link-local, and reserved ranges by default, and closes the DNS-rebinding gap by re-checking resolved addresses at actual connect time, not just at request construction.

Dashboard

Eleven tabs, zero build step.

Pure vanilla JS, served straight from the gateway at /dashboard — no npm install, no separate frontend deploy.
